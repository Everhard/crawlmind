# crawlmind-mcp

MCP server for AI-native SEO audits. This package is a shortcut that runs
[`crawlmind mcp`](https://github.com/Everhard/crawlmind); all features and docs live there.

```bash
claude mcp add crawlmind -- npx -y crawlmind-mcp
```

```json
{
  "mcpServers": {
    "crawlmind": { "command": "npx", "args": ["-y", "crawlmind-mcp"] }
  }
}
```
